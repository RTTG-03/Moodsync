# MoodSync

MoodSync is a beginner-built web prototype that suggests music based on sample wearable readings and optional mood input.

## Try the prototype

[Open MoodSync](https://rttg-03.github.io/Moodsync/)

## Features

- Demo inputs for heart rate, sleep, and activity
- Optional manual mood and context selection
- Simple, transparent rule-based mood estimate
- Predefined music suggestions
- Feedback that changes the suggestions

## Important note

This prototype does not connect to a smartwatch or music streaming service. Its estimates are for demonstration only and are not a medical or emotion diagnosis.

## Built with

HTML, CSS, and JavaScript
